# 更新阶段状态管理

### 思考部分：

1、为什么setState方法触发了函数重新执行，但拿到的状态还是初始值呢？当前实现的useState每次执行时都会设置初始值，也就是说没有区分首次和更新的区别。

2、那首次和更新有什么区别么？就是看当前的Fiber对象的memoizedState是不是null，是null就是首次，有值就是更新

3、既然判断memoizedState值就能判断是首次还是更新，为什么还要拆成两个方法？

- 关注点分离，一个方法尽可能只专注解决一个事情，这样在以后拓展的时候便于调整

- 除了return，基本上其他的逻辑在创建和更新时，都不一样，所以代码书写层面也是拆开比较好

4、但是开发者在使用的时候只用useState，并没有区分首次还是更新，怎么做到的？导出一个变量，根据不同情况给这个变量设置不同的方法。

5、什么时候进行设置呢？确定当前是函数组件，同时得在函数执行前，最合适的时机就是renderWithHook方法中

6、为什么更新选然后会多出dom元素？每次更新直接执行appendChild，只会拼接内容，而不会对原本的dom元素进行清空。

7、为什么一定要清空？一棵Fiber树就对应一组dom，如果Fiber树每增加，那dom也不应该增加，所以需要将之前的dom移除

### 实操部分：

1、修改FiberHook.ts，将useState方法拆成两个，并在renderWithHooks方法中判断

```typescript
/**
 * 首次构建时状态管理的hook
 * 1、创建一个hook
 * 2、将hook挂载到fiber的memoizedState上
 * 3、返回状态和更新状态的方法
 * @param initialState 初始状态
 * @returns [state,setState]
 */
export function mountState(initialState:any){
    const hook={
        memoizedState:initialState,
    }
    currentlyRenderingFiber!.memoizedState = hook;
    return [hook.memoizedState,setState];
}

/**
 * 更新时状态管理的hook
 * 1、获取当前fiber的hook
 * 2、返回状态和更新状态的方法
 * @param 
 * @returns [state,setState]
 */
export function updateState(){
    const hook = currentlyRenderingFiber!.memoizedState;
    return [hook.memoizedState,setState];
} 
// 定义一个导出当前状态的hook
export let useState:any=null;
/**
 * 渲染函数组件，考虑hooks，并返回组件的返回值
 * 1、设置当前正在渲染的fiber
 * 2、执行函数组件的函数
 * @param workInProgress 当前正在渲染的fiber
 * @param Component 函数组件
 * @returns 组件的返回值
 */
export function renderWithHooks(workInProgress:Fiber, Component:any) {
    currentlyRenderingFiber = workInProgress;
    if(currentlyRenderingFiber!.memoizedState === null){
        useState = mountState;
    }else{
        useState = updateState;
    }
    return Component();
}
```

2、修改FiberConfigDOM.ts，增加移除元素的功能

```typescript
/**
 * 删除dom节点
 * @param parent 父节点
 * @param child 子节点
 */
export function removeChild(parent:Instance,child:Instance){
    parent.removeChild(child);
}
```

3、修改WorkLoop.ts，增加移除元素逻辑

```typescript
/**
 * 更新Fiber树
 * @param fiber 
 */
export function updateOnFiber(fiber:Fiber){
    const hostRootFiber = getRootForUpdateFiber(fiber);
    removeChild(hostRootFiber.stateNode.containerInfo,hostRootFiber.child?.stateNode);
    workLoop(fiber);
    
    appendChild(hostRootFiber.stateNode.containerInfo,hostRootFiber.child?.stateNode);
}
```
