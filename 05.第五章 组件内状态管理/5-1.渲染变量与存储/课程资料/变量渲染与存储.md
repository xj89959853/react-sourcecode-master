# 变量渲染与存储

### 思考部分：

1、开发中，页面展示不会只用纯静态内容，更多的是需要能展示变量的内容，也就是数据展示，所以需要扩展能将变量的内容设置到fiber中。能展示的内容基本上只有字符串和数值，对象和数组也会通过babel转译成字符串和数值。

2、既然是变量，那就表示内容可变，而内容变化后会出现什么影响呢？fiber变化->dom变化

3、那fiber的什么变化呢？一个新的属性，叫memoizedState，记忆的状态，记忆就是已经发生的，状态就是能改变组件渲染的数据，换句话说就是已经确认的能改变组件渲染的数据。

4、那这个属性存什么呢？不同的类型存的是不同的

- HostRootFiber：存的是一个对象，对象中有一个element属性是存储根节点组建的，也就是<APP/>

- 函数组件：主要是hook

- 类组件：存储组件的 state 对象

- HostComponent、HostText：null

### 实操部分

1、Fiber增加memoizedState属性。/packages/reconciler/ReactInternalTypes.ts

```typescript
export type Fiber ={
    memoizedState:any
}
```

2、构造函数增加memoizedState默认值。/packages/reconciler/Fiber.ts

```typescript
export function createFiber(){
    const fiber={
        memoizedState:null
}
}
```
