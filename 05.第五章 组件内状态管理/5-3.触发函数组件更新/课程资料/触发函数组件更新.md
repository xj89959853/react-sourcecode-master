# 触发函数更新

### 思考部分：

1、要想更新组件状态需要做什么？更新状态值和重新渲染组件

2、函数组件的重新渲染本质是什么？函数执行。只需要让函数重新执行，返回一个新的ReactElement对象，就可以在进入到workLoop的循环，重新构建Fiber树，然后再触发dom更新



### 实操部分：

1、修改FiberHook.ts

```typescript
/**
 * 更新组件状态 
 * 1、更改状态值
 * 2、更新Fiber树
 * @param newState 
 */
function setState(newState: any) {
    const hook = currentlyRenderingFiber!.memoizedState;
    hook.memoizedState = newState;
    console.log('setState',newState);
    updateOnFiber(currentlyRenderingFiber!);
}
```

2、修改WookLoop.ts

```typescript
/**
 * 向上获取hostRootFiber
 * @param fiber 
 * @returns hostRootFiber
 */
function getRootForUpdatedFiber(fiber:Fiber):Fiber{
    let node:Fiber=fiber;
    while(node.return){
        node=node.return;
    }
    return node;
}

/**
 * 更新Fiber树  
 * @param fiber 
 */
export function updateOnFiber(fiber:Fiber){
    const hostRootFiber:Fiber=getRootForUpdatedFiber(fiber);
    workLoop(hostRootFiber.child!);
    appendChild(hostRootFiber.stateNode.containerInfo,hostRootFiber.child?.stateNode);
}
```

```typescript
test('测试函数组件State Hook创建',async ()=>{
        jest.useRealTimers();
        const root_dom = document.createElement('div');
        const hostRootFiber = createContainer(root_dom);
        updateContainer(<p><App2/></p>,hostRootFiber);

        expect(hostRootFiber.child?.tag).toBe(HostComponent);
        expect(hostRootFiber.child?.child?.tag).toBe(FunctionComponent);
        expect(hostRootFiber.child?.child?.memoizedState).not.toBeNull();
        expect(hostRootFiber.child?.child?.memoizedState.memoizedState).toBe(0);
        expect(hostRootFiber.child?.child?.child?.pendingProps.children).toBe(0);
        // 等待足够的时间让 setTimeout 执行
        await new Promise(resolve => setTimeout(resolve, 1100)); // 多等100ms确保执行
    })
```

补充说明：

jest做测试时，如果有定时器，在定时器没开始时，jest可能就运行完成并关闭，所以定时器就看起来不会生效，两种方式解决：

- 使用真定时器`jest.useRealTimers();`，思路就是让当前测试用例等待一段时间`async...await...`，等待时常大于测试内容的计时器（当前处理）

- 使用假定时器`jest.useFakeTimers();`，需手动触发定时器，`jest.runAllTimers();`
