# 初识双缓存

### 思考部分：

1、双缓存

- 概念：
  
  - 使用两个缓冲区（Buffer）来存储数据
  
  - 一个缓冲区用于显示（当前状态）
  
  - 另一个缓冲区用于更新（工作状态）
  
  - 两个缓冲区交替使用

- 工作流程
  
  - 当需要更新时，在非显示缓冲区进行修改
  
  - 修改完成后，交换两个缓冲区
  
  - 原来的显示缓冲区变成工作缓冲区
  
  - 原来的工作缓冲区变成显示缓冲区

- 优势
  
  - 避免画面撕裂（Screen Tearing）
  
  - 保证显示内容的完整性
  
  - 提高渲染效率
  
  - 支持并发操作

2、保证渲染的完整性，那什么情况下会出现不完整？可中断渲染和优先级实现后会出现

3、那为什么现在要实现？`因为可能要下雨，所以需要带伞，带伞是先发生的，下雨是后发生的，但是先发生的事情是因为后发生的事情而禅产生的`，而且一些与双缓存关系不大的优化也会因为双缓存结构调整代码，如果之后在调整工作量比较大

```typescript
/**
 * 创建工作中的fiber
 * @param current 当前的fiber
 * @param pendingProps props
 * @returns 工作中的fiber
 */
export function createWorkInProgress(current:Fiber,pendingProps:any):Fiber{
    let workInProgress = current.alternate;
    if(workInProgress === null){
        workInProgress = createFiber(current.tag,current.key,pendingProps);
        workInProgress.type = current.type;

        workInProgress.alternate = current;
        current.alternate = workInProgress;
    }else{
        workInProgress.pendingProps = pendingProps;
}
    return workInProgress;
}
```
