# 函数组件的实现

### 思考部分：

1、支持函数组件等于支持函数的写法，并能成功渲染成HTML

2、怎么能让函数渲染成HTML？

标签写法->jsx->ReactElement->Fiber->dom

函数->jsx->ReactElement->Fiber->dom

所以目标就是让函数对应的ReactElement可以正常渲染成Fiber，就是支持函数组件。

3、函数组件生成的ReactElement特点？ReactElement不完整，pendingProps是{}，没法构建子Fiber

4、怎么拿到函数组件里面的ReactElement？执行函数，返回值是ReactElement。

5、HTML是由Fiber渲染的，所以还需要看一下函数组件对应的Fiber节点的特点，stateNode是null，所以没有dom实例

6、函数组件的fiber没有dom实例，那怎么做dom关联？直接将fiber的父节点和fiber的子节点的dom实例关联

7、那基于我们当前的流程，需要修改哪些地方呢？

- 生成Fiber节点——支持函数组件节点

- 构建节点——处理是函数组件的情况，不能直接传pendingProps

- 完成节点——跳过Fiber节点，让fiber子节点的stateNode直接挂到fiber父节点的stateNode上

2、增加beginWork处理逻辑

```typescript
 switch(fiber.tag){
        case HostText:
            return null;
        case FunctionComponent:
            const children = fiber.type();
            fiber.child = reconcileChildFibers(fiber,children);
            return fiber.child;
        case HostComponent:
            fiber.child = reconcileChildFibers(fiber,fiber.pendingProps.children);
            return fiber.child;
        default:
            return null;
    }
```

3、增加completeWork处理逻辑

```typescript
function appendAllChildren(parent:Instance,child:Fiber|null){
   let node:Fiber|null = child;
   while(node){
     let childStateNode = node.tag === FunctionComponent?node.child!.stateNode:node.stateNode;
     appendChild(parent,childStateNode);
     node = node.sibling;
   }
```
