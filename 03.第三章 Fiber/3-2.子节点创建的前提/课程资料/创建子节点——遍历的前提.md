# 创建子节点——遍历的前提

### 思考部分：

1、当前的fiber对象能否支持遍历？不可以，当前只有连接节点，而且初始化时还设置成了null，没有和子节点间的参考属性。

2、已知的对象中，哪个对象可以做遍历？ReactElement，ReactElement的props属性就可以用来遍历。

3、为什么不直接遍历ReactElement？不同的数据结构服务不同的目的，ReactELement是单纯描述UI的，而Fiber是React核心功能的操作对象，也就是说，React的一切功能是围绕Fiber展开

4、那怎么解决？将ReactElement的props赋值给一个新的属性——pendingProps

### 实操部分：

1、修改Fiber定义，以及初始化方法，增加pendingProps的

2、创建packages/reconciler/beginWork.js

```typescript
import { createFiberFromElement } from './Fiber';
import type {Fiber} from './ReactInternalTypes';

export function beginWork(fiber:Fiber):Fiber|null{
    return createFiberFromElement(fiber.pendingProps.children);
}
```
